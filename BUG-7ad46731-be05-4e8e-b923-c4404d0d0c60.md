# BUG-7ad46731-be05-4e8e-b923-c4404d0d0c60

Renderer throws cite an SMS id that does not exist.

## Owning repository

`network-renderer-nebula`.

## Finding

`network-renderer-nebula` raises provider-contract errors citing
`FS-310-HDS-010-SDS-010-SMS-110`. That id is not in the controlled tree:

- `GAMP/SMS/FS-310-HDS-010-SDS-010` in `network-codex-agent` runs
  `SMS-010`, `SMS-020`, `SMS-030`, `SMS-120`, `SMS-130` — there is no `SMS-110`.
- `git log --all -- GAMP/SMS/FS-310-HDS-010-SDS-010-SMS-110.md` in
  `network-codex-agent` is empty, so it never existed and was not deleted.

Every throw in the renderer that cites it:

```
s88/Enterprise/runtime/nixos-module.nix:58
  listenHost = runtimeNode.service.listenHost or (throw "FS-310-HDS-010-SDS-010-SMS-110: service.listenHost required for runtime node ${nodeName}");
s88/Enterprise/bootstrap/nixos-module/advertised-unsafe-networks.nix:27
s88/Enterprise/bootstrap/nixos-module/lighthouses.nix:23,39,63,74
```

## Why it matters (concrete, reproduced)

The `listenHost` throw is unsatisfiable, because
`network-control-plane-model` never emits `service.listenHost` and no spec tells
it to. The `network-labs` active-lab dry-run sweep therefore fails to evaluate a
`s-router-nixos` configuration:

```
error: FS-310-HDS-010-SDS-010-SMS-110: service.listenHost required for runtime
node nixos-router-core-nebula
```

Reproduce in `network-labs`:

```
NETWORK_LABS_NIXOS_REPO=~/github/nixos bash \
  tests/lib/FS-010-HDS-010-SDS-010-SMS-010/test-active-lab-shim-nixos-dry-runs.sh
```

## Requested fix

One of:

1. Cite the SMS id that actually owns the runtime-node contract, and make the
   field it requires (`service.listenHost`) something `network-control-plane-model`
   is specified to emit; or
2. If `FS-310-HDS-010-SDS-010-SMS-110` is the intended row, add it to the
   controlled tree so the throw cites a consultable authority.

## Note

There are five distinct SMS ids cited as authority in the renderer. Four
resolve against `network-codex-agent/GAMP/SMS`; only this one does not.
